## “香港三网优化VPS”到底优化了什么

优化的是香港机房到大陆用户之间那段回程路由，不是机房位置本身。香港到华南的物理延迟理论上能到个位数毫秒，但大陆流量默认走中国电信 163 骨干网（AS4134），这条公共通道承载了全国绝大多数民用流量，晚高峰被视频、下载、游戏挤满，延迟从白天的三四十毫秒跳到 100ms 以上，丢包率能到两位数。

绕开这条拥堵通道的方式，决定了你付的钱买到什么：

- **CN2 GIA**：电信 AS4809 里的最高一档，去程回程全程走专网。路由追踪的特征是 `59.43.x.x` 节点从用户本地出来很快就出现，并且一直持续到香港机房。晚高峰延迟通常稳定在 30–50ms，丢包极低。代价是带宽贵，香港机房拿到的 GIA 带宽本身就少，市面上 GIA 机器普遍只有 10–30Mbps。
- **CN2 GT**：国内段走 163（`202.97` 节点），到国际出口才切进 `59.43`。最容易堵的那一段被保留了下来，晚高峰只是比纯 163 好一点。很多标“CN2”不写 GIA 的机器默认就是 GT，甚至是去程 GT、回程 163 的半程方案。
- **AS9929 / AS10099**：联通的精品网，比普通 AS4837（169 网）路由更短更稳。
- **CMI**：中国移动国际（AS58453），主要走香港到广州的陆缆入境，是移动宽带访问香港延迟最低的路径。

“三网优化”指的是电信、联通、移动三家分别接入了优质出口。市面上不少标着优化的机器只接了其中一条或两条，剩下的走普通 BGP 绕路。BGP 和 CN2 解决的不是同一个问题：BGP 是机房接入多家运营商动态选路，优势在均衡和冗余；但接入普通 163、4837、CMI 的 BGP 和接入 CN2 GIA、9929、CMI 精品的 BGP 都叫“BGP 多线”，晚高峰表现能差好几个档次。

**自己验的方法**：拿到测试 IP 后，用电信、联通、移动三张网分别跑 mtr 或 traceroute，看回程。

- 电信看有没有连续的 `59.43` 节点。只有出国段出现 `59.43`、国内段全是 `202.97`，那是 GT，不是 GIA。
- 联通看 `218.105` 或 `210.51`。
- 移动看 `223.120` 或 `221.176`。
- 如果只有去程漂亮、回程绕路，或者三网回程全挤在同一个出口上，标签写得再好也是伪优化。

## 常见问题

**250GB 月流量够用吗？**

纯文字博客、API 接口、后台管理、SSH 运维，一个月通常跑不到 100GB。带图的站点、有下载的站点，250GB 会紧张。图片站和文件站建议直接看 VM-2 的 1000GB。

**Premium 和标准线路的差别只有流量吗？**

从价格页能确认的差别就是流量，同配置下香港的月流量是标准线路的一半到三分之一，价格相同。路由层面的差异官方没有公开明细，需要自己验。如果你对大陆访问质量没有硬要求，标准线路同价拿到双倍流量更划算。

**月付还是长约？**

价格页没有年付折扣，长约不省钱。先用月付跑一个完整计费周期，跨过一次晚高峰，确认回程路由和稳定性符合预期，再考虑要不要长期持有。

**香港节点适合建站吗？**

适合面向大陆和东南亚用户的站，不需要备案。VM-1.5 的 2 核 2GB 跑 WordPress 加 MySQL 是够的，但要把 500GB 流量算进去，图片多的站要么上对象存储，要么直接选 VM-2。

**能不能装 Windows？**

第三方整理称支持 Windows Server 2012/2016/2022，官方价格页没有这条说明。真要装，先确认授权方式和内存要求，512MB 和 1GB 的档位装不了。

**IP 被墙了怎么办？**

价格页没有公开换 IP 政策。额外 IP 是 $3/月，属于付费增项，不是免费更换。这类问题在下单前问客服比事后处理省事。
